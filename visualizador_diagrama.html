📋 Información del Sistema

🎯 Objetivo del Sistema

Proporcionar control inteligente para sesiones de rehabilitación mediante el monitoreo de parámetros fisiológicos y control automático de resistencia en cicloergómetros estacionarios.

🧠 Arquitectura MISO

Múltiples Entradas (3 sensores) → Una Sola Salida (control de motor). Los datos de los sensores convergen en el microcontrolador que procesa y genera señales de control unificadas.

⚡ Componentes Principales

Sensores biométricos, microcontrolador ATmega328P, controlador de motor (Puente H), motor DC y cicloergómetro estacionario para la rehabilitación del paciente.

🔧 Especificaciones Técnicas

  • Microcontrolador: ATmega328P (Arduino) - 16MHz, 32KB Flash, 2KB SRAM
  • Sensores: Pulso cardíaco, temperatura corporal, movimiento (IMU)
  • Controlador de Motor: Puente H para control bidireccional de motor DC
  • Actuador: Motor DC con control de velocidad y dirección
  • Interfaz: Cicloergómetro estacionario para rehabilitación
  • Protocolo de Comunicación: Serial/UART para transmisión de datos
